# Piton Docs

Documentation site for the Piton language and the Belay framework, built with
[Astro](https://astro.build) and [Starlight](https://starlight.astro.build).

## Structure

```
src/content/docs/
  index.mdx              Landing page
  introduction/          The essay: thesis, CNC comparison, agent as compiler, the problem
  language/              Language reference: types, variables, operators, anchors, modules
  cli/                   CLI compiler and piton.config.pi
  frameworks.md          Frameworks overview
  belay/                 The Belay framework: constructs and serialization
```

Sidebar groups are configured in `astro.config.mjs`; pages within the
`introduction`, `language`, and `cli` groups are autogenerated and ordered by
the `sidebar.order` value in each page's frontmatter.

Piton code blocks are tagged ` ```piton `. Highlighting uses Piton's own
TextMate grammar, vendored into `src/grammars/` from the compiler repo and
registered via `markdown.shikiConfig.langs` — see `src/grammars/README.md`.

## Commands

| Command             | Action                                      |
| ------------------- | ------------------------------------------- |
| `npm install`       | Install dependencies                        |
| `npm run dev`       | Start the dev server at `localhost:4321`    |
| `npm run build`     | Build the production site to `./dist/`      |
| `npm run preview`   | Preview the build locally                   |
