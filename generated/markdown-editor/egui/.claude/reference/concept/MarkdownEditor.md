# Markdown Editor

## Purpose

A single-window editor for one Markdown file at a time.

## Parts

The window is one column. [Toolbar](Toolbar.md) sits along the top and [Editor](Editor.md) fills the rest.

## Out Of Scope

- No tabs; one file is open at a time.
- No preview pane; the editor styles its own text.
- No settings, themes, or plugins.

Links in this document point at reference files. Read one when the work touches what it describes.
