## Bugs and feature requests

Open an issue on
[GitHub](https://github.com/piton-lang/piton-rs/issues). For a compiler bug,
include the output of `piton --version`, the smallest `.pi` source that
reproduces it, and what you expected it to compile to.

## Questions and discussion

Ask in
[GitHub Discussions](https://github.com/piton-lang/piton-rs/discussions) —
how to specify something, whether Piton fits a project, or an idea not yet
ready to be an issue. Answers there are public, so the next person with the
same question can find them.

## Email

For anything that does not belong in public, write to
[derek@mdynx.com](mailto:derek@mdynx.com).
