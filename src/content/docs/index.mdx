import { Card, CardGrid } from "@astrojs/starlight/components";

<CardGrid>
  <Card title="Structure and Prose as First-Class Peers" icon="document">
    Markdown has no tools for reuse. Traditional programming languages have
    clumsy mechanisms for prose. Piton gives you inheritance, imports, and type
    constraints while `the button should be blue` stays a sentence.
  </Card>
  <Card title="Compile to Data" icon="rocket">
    Piton has no runtime; JSON, YAML, Markdown are the build artifacts. There is
    nothing to execute, only something to build.
  </Card>
  <Card title="Anchors" icon="puzzle">
    One extensible data type. Named structural declarations that participate in
    inheritance, typing, exports, and composition allow you to build the
    structure of your code as your descibe it.
  </Card>
  <Card title="The Belay Framework" icon="setting">
    Bundled with Piton, Belay adds `agent`, `skill`, `command`, and
    `instruction` keywords that compile into agentic Markdown so the agent
    already knows what you want to build.
  </Card>
</CardGrid>
